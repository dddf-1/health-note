## 1. 서비스 기획 (사전 점검)

### 1-1. 내가 만들고 싶은 서비스 — 4가지 질문

| 질문 | 답변 |
| --- | --- |
| 1. 무엇을 만들 것인가? | 헬스장에서 세트마다 빠르게 입력하고, 지난 기록과 비교해 성장을 확인하는 **개인용 운동 기록 앱** |
| 2. 왜 만들어야 하는가? | 기존 앱은 입력이 번거롭거나(매번 팝업으로 숫자 입력), 핵심 기능이 유료이거나, 내가 안 쓰는 기능(소셜·AI 추천·식단)이 많아서 |
| 3. 어떻게 만들 것인가? | 지난 기록 자동 채움 + 버튼 한 번으로 세트 완료, 루틴 템플릿, 휴식 타이머, 종목별 성장 그래프. 데이터는 내 기기에 저장하고 내보내기 지원 |
| 4. 예상되는 문제·리스크는? | ① 이미 무료로 좋은 앱(Hevy 등)이 있어 "직접 만들 이유"가 약할 수 있음 ② 혼자 개발하므로 범위가 커지면 완성 못 함 ③ 기기 분실·앱 삭제 시 데이터 유실 ④ 꾸준히 쓰지 않으면 의미 없음 |

### 1-2. 생각 나누기 (셀프 피드백)

팀원이 없으므로, 나중에 같이 운동하는 지인·동기에게 받으면 좋을 질문으로 대신합니다.

| 예상 의견 | 반영 방향 |
| --- | --- |
| "그냥 Hevy 쓰면 되지 않아?" | 차별점을 **입력 속도**와 **내 데이터 소유**로 좁히고, 기능 수로 경쟁하지 않음 |
| "운동 중엔 폰 만지기 귀찮다" | 한 세트 기록을 **탭 1번**으로 끝내는 것을 핵심 목표로 둠 |
| "기록해도 다시 안 본다" | 홈 화면에서 "지난번 대비 +2.5kg" 같은 비교를 바로 보여줌 |

### 1-3. 케이스 스터디

| 분석 대상 | 분석 포인트 (UX 요소) | 분석 결과 (목적 및 이유) |
| --- | --- | --- |
| 경쟁 서비스: Strong | 세트 행에 이전 기록이 회색으로 미리 표시되고, 체크 버튼으로 완료 → 휴식 타이머 자동 시작 | 입력을 "확인" 동작으로 바꿔 운동 흐름을 끊지 않음. **내 앱의 핵심 UX로 참고** |
| 다른 업계 서비스: 토스(송금) | 최근 보낸 사람·금액을 먼저 보여주고, 숫자 키패드를 화면에 바로 띄움 | 반복 작업은 "지난번 값 재사용"이 가장 빠름. 무게·횟수 입력에 같은 원리 적용 |

> 교재 권장 사항: 두 서비스를 직접 써 보면서 화면 흐름을 그림으로 필사해 보세요. (이 문서에는 텍스트로만 정리)

## 2. 자료 조사 (Research)

데스크리서치 방식으로 통계·스토어 정보·리뷰를 수집했습니다.

### 2-1. 시장·사용자 현황

| 항목 | 내용 | 출처 |
| --- | --- | --- |
| 규칙적 체육활동 참여율 | 2025년 62.9% (주 1회·30분 이상), 전년 60.7% 대비 +2.2%p. 주 2회 이상은 52.2% | 문체부 2025 국민생활체육조사 |
| 많이 하는 종목 | 걷기 40.5% > **보디빌딩(헬스) 17.5%** > 등산 17.1% | 같은 조사 |
| 운동 안 하는 이유 | "시간 부족" 58.4% | 같은 조사 |
| 정책 동향 | 2026년 체육시설 포인트 적립 확대, 달리기·자전거 등 야외 활동도 운동 앱과 연계 예정 | 같은 발표 |

### 2-2. 사용자 리뷰에서 반복되는 불편 (앱스토어)

1. **무게·횟수를 매번 직접 타이핑** — "매번 무게를 직접 창을 띄워서 입력해야 돼서 너무 불편" 류의 리뷰
2. **+/− 화살표로 빠르게 조절하고 싶다**, 루틴을 미리 만들어 한 번에 불러오고 싶다
3. **부위 분류가 거침** (팔 → 이두/삼두 세분화 요청), 사진(눈바디·인바디) 첨부 요청
4. **유료 장벽** — 무료 버전은 루틴 수 제한 등
5. **종목 편중** — 대부분 웨이트 중심이라 다른 운동은 기록하기 어려움

### 2-3. 시사점

- 헬스(보디빌딩)는 걷기 다음으로 많이 하는 종목이라, 웨이트 기록 앱 수요는 충분함.
- 불편의 핵심은 기능 부족이 아니라 **입력 마찰**과 **유료 장벽**.
- "시간 부족"이 가장 큰 이유인 만큼, 기록 자체가 운동 시간을 잡아먹으면 안 됨.

> 한계: 리뷰 표본이 앱별로 수십 건 수준이라 일반화하기 어렵습니다. 실제로 쓰는 앱의 리뷰를 더 모으거나, 나의 불편을 일주일 기록해 보면 근거가 단단해집니다.

## 3. 문제 정의 (Problem Definition)

### Q1. 만들고 싶은 서비스는 무엇인가요?
1. 세트 기록을 탭 한 번으로 끝내는 개인용 헬스 운동 기록 앱

### Q2. 사람들(나)에게 왜 필요할까요?
1. 운동 중 무게·횟수를 매번 타이핑하는 게 번거로워 기록을 빼먹게 됨
2. 지난번에 몇 kg을 몇 회 했는지 기억이 안 나 점진적 과부하를 계획하기 어려움
3. 기존 앱은 광고·구독·소셜 기능이 많아 정작 필요한 기록 화면이 복잡함

### Q3. 어떤 사람들에게 필요할까요?
1. 나 (주 3~4회 헬스장에 가는 직장인·학생)
2. 루틴을 스스로 짜서 운동하는 중급자
3. 종이 노트나 메모 앱으로 기록하다 지친 사람

### Q4. 다른 서비스에서는 제공할 수 없는 서비스인가요?
제공할 수 있습니다. Strong·Hevy는 이전 기록 표시와 체크 방식 입력을 이미 제공합니다.

### Q4-1. 그럼에도 왜 내가 만든 서비스를 사용해야 하나요?
1. 내 운동 방식(부위 분류, 종목, 화면 구성)에 100% 맞출 수 있음
2. 구독료·광고 없이 모든 기능 사용, 데이터는 내 기기에 저장하고 언제든 내보내기 가능
3. 직접 만들면서 기획 → 설계 → 개발 전 과정을 연습하는 **포트폴리오** 가치가 있음

### Q4-4. 정말로 존재하는 시장일까요?
시장은 이미 크고 경쟁이 치열함. 따라서 이 프로젝트의 목표는 시장 점유가 아니라 **"내가 매일 쓰는 앱"**을 만드는 것으로 범위를 정함.

### Q5. 서비스의 목표가 어떻게 되나요?
1. 운동 기록에 쓰는 시간을 세트당 3초 이내로 줄이고, 4주 연속 빠짐없이 기록하는 것

## 5. 경쟁사 분석 (Competitor Analysis)

교재의 「경쟁사 분석」 표 항목(서비스명, 회사명, 슬로건, 장점, 단점, 비고 등)에 맞춰 작성했습니다.
월간 트래픽은 공개 자료가 없어 비웠습니다.

| 서비스명 | 회사명 | 슬로건/포지션 | 장점 | 단점 | 비고 |
| --- | --- | --- | --- | --- | --- |
| **Strong** | Strong Fitness (해외) | 군더더기 없는 웨이트 기록기 | 이전 기록 표시 + 체크 입력이 매우 빠름, 애플워치 완성도 높음 | 무료 버전은 루틴 수 제한, 구독 $4.99/월 수준, 한국어 운동명 부족 | 내 앱 UX의 기준점 |
| **Hevy** | Hevy Studios (해외) | 소셜 기능이 있는 운동 기록 앱 | 무료 범위가 넓음, iOS·Android·워치 지원, 피드·랭킹 | 소셜·피드가 기록 화면을 복잡하게 만듦, 구독 $3.99~4.99/월 수준 | 무료로 가장 강력한 대안 → 직접 만들 이유를 명확히 해야 함 |

| **번핏** | (주)버닛 | 운동일지 + 식단·칼로리 통합 | 운동·식단을 한곳에서 관리, 한국어 친화 | 기능이 많아 기록 화면이 무거움 | 2021 시드 투자, 글로벌 누적 다운로드 100만 보도 |
| **짐워크** | 국내 개발사 | 지난 기록 기반 무게·횟수 추천 | 점진적 과부하 추천, 앱스토어 평점 4.8 | 평가 수가 적음(수십 건), AI 기능 일부 유료 | 내 앱과 방향이 가장 비슷 |
| **메모 앱·종이 노트** | — | 가장 흔한 대체재 | 자유도 최고, 무료 | 비교·그래프 불가, 검색 어려움 | 실제 최대 경쟁자 |

### 5-1. 차별화 포인트

| 구분 | 경쟁 서비스 | 내 앱 |
| --- | --- | --- |
| 입력 | 이전 기록 표시(Strong) 또는 팝업 타이핑 | 이전 기록 **자동 채움** + +/− 버튼, 세트 = 탭 1번 |
| 가격 | 핵심 기능 구독 | 전부 무료 (나만 씀) |
| 기능 범위 | 소셜·AI·식단까지 확장 | 기록·비교·그래프만. 기능 추가보다 속도 우선 |
| 데이터 | 회사 서버 | 내 기기 저장 + 내보내기 |
| 맞춤성 | 정해진 운동 목록 | 내 부위 분류·종목을 직접 편집 |

### 5-2. 결론 (경쟁사 분석 보고서 요약)

- 기능 수로는 Strong·Hevy를 이길 수 없고, 그럴 필요도 없음.
- **입력 속도 · 무료 · 내 데이터 · 내 맞춤**이라는 4가지에 집중한 MVP를 먼저 만들어 4주간 직접 써 봄.
- 2차로 캘린더·백업을 붙이고, 사진·워치 연동은 실사용 후 다시 판단.
