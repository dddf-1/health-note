# 나만의 헬스 노트

> 지난번 기록이 미리 채워져 있어, 체크 한 번이면 끝나는 나만의 헬스 노트

아이폰 홈 화면에 추가해서 쓰는 개인용 운동 기록 웹앱(PWA)입니다. 서버·로그인 없이 기록은 기기 안(IndexedDB)에만 저장됩니다.

- 앱: https://dddf-1.github.io/health-note/ (아이폰 Safari → 공유 → 홈 화면에 추가)
- 기획 문서: Notion 「프로젝트」 페이지 (초기 버전 사본: [docs/운동기록앱_기획_v0.1.md](docs/운동기록앱_기획_v0.1.md))

## 기능

| 탭 | 할 수 있는 것 |
| --- | --- |
| 홈 | 오늘의 루틴 추천(순환), 운동 시작·이어하기, 이번 주 운동일/목표, 지난 운동의 종목별 지난번 대비 |
| 운동 | 지난 기록 자동 채움, 무게·횟수 +/−, 체크하면 휴식 타이머(0초 알림음·화면 켜짐 유지), 최고 기록 🏆, 세트 추가·밀어서 삭제·되돌리기, 운동 중 종목 추가, 완료 요약·메모 |
| 기록 | 월별 운동 목록, 상세에서 세트 값·메모 고치기, 기록 삭제 |
| 성장 | 종목별 최고 무게·추정 1RM·볼륨 그래프와 날짜별 기록 |
| 설정 | kg/lb, +/− 무게 단위, 기본 휴식, 주간 목표, 루틴 만들기·고치기·순서, 직접 종목 추가, 백업 저장·복원, 엑셀용 CSV |

처음 열면 무게 단위와 주간 목표만 묻고 바로 시작합니다.

### 아이폰에서 알아 둘 것

- 화면이 꺼져 있으면 휴식 알림음·진동이 울리지 않습니다(웹앱 한계). 운동 중에는 화면이 꺼지지 않게 유지합니다.
- 홈 화면에 추가해야 저장 공간이 오래 보관됩니다. 그래도 폰을 바꾸거나 앱을 지우면 사라지니 **설정 → 백업 저장**을 가끔 해 두세요.

## 기술 스택

| 영역 | 선택 |
| --- | --- |
| 화면 | React + TypeScript + Vite |
| 기기 저장 | IndexedDB (Dexie.js, dexie-react-hooks) |
| 그래프 | Recharts (성장 탭을 열 때 불러옴) |
| 오프라인·홈 화면 설치 | vite-plugin-pwa |
| 테스트·린트 | Vitest + fake-indexeddb, oxlint |
| 배포 | GitHub Actions → GitHub Pages (main 에 푸시하면 테스트·빌드 후 배포) |

## 코드 구조

```
src/
  domain/rules.ts     계산 규칙 (자동 채움, 1RM, 최고 기록, 주간 운동일, 추천)
  db/                 저장·조회 (repo: 운동·세트·루틴, history: 기록·성장,
                      manage: 설정·종목·루틴 편집, backup: 백업·CSV)
  screens/            화면 (홈·운동·요약·기록·상세·성장·설정·루틴 편집·첫 실행)
  components/         세트 행, 휴식 바, 종목 고르기, 확인 창, 탭 바, 백업 카드
```
